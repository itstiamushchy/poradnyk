# ВІХА — Картки Знань

Інтерактивний довідник у форматі карток для швидкого навчання і повторення матеріалу.

🌐 **[https://itstiamushchy.github.io/poradnyk/](https://itstiamushchy.github.io/poradnyk/)**

---

## Про проєкт

**ВІХА** — це офлайн-готовий прогресивний веб-застосунок (PWA) без зовнішніх залежностей. Увесь код — чистий HTML / CSS / JavaScript. Контент організований у 7 розділів та понад 35 блоків, охоплює 2001 картку від шкільних навичок до підприємництва і маркетингу.

Кожна картка містить:
- **rule-note** — ключовий принцип або визначення
- **steps** — покрокова інструкція (3–7+ кроків, залежно від теми)
- **final-note** — підсумок або порада

---

## Стек

- Vanilla HTML / CSS / JS
- Без залежностей (нульовий npm)
- Дані — масив у файлах `data/cat-*.js`

## Запуск

```
Відкрити index.html у браузері
```

## Формат картки (внутрішній)

```js
[id, "Назва картки", "<html>"]
```

Структура HTML:

```html
<div class="rule-note">Ключовий принцип</div>
<div class="step c1"><div class="step-num">1</div><div class="step-text">…</div></div>
<div class="step c2"><div class="step-num">2</div><div class="step-text">…</div></div>
<!-- … до 7+ кроків; кольори циклічно: c1 → c2 → c3 → c1 … -->
<div class="final-note">Підсумок або порада</div>
```

## Принципи контенту

- Тільки реальні, перевірені дані.
- Без вигаданих відсотків і псевдоточних тверджень.
- Якщо факт сумнівний — формулювати обережно («зазвичай», «як правило») або не включати.
- Кількість кроків у картці — стільки, скільки потрібно для розкриття теми (не фіксована).
