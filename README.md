# ВІХА — Картки Знань

Інтерактивний довідник у форматі карток для швидкого вивчення та повторення матеріалу.

## Стек
- Vanilla HTML / CSS / JS
- Без залежностей

## Запуск
Відкрити `index.html` у браузері.

## Структура
```
index.html      — головна сторінка
cards/          — JSON-файли з картками по темах
assets/         — стилі, іконки, логотип
```
